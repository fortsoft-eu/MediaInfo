Нативный просмотрщик отчётов MediaInfo.dll для Windows x86. У каждого файла своя вкладка только для чтения.

## Сборка

Откройте MediaInfo.sln в Visual Studio 2015 с установленным набором инструментов Visual C++ v140. Выберите Release | Win32 и создайте решение. Единственная платформа приложений — Win32 (x86).

[PCRE2 10.49](https://github.com/PCRE2Project/pcre2/tree/pcre2-10.49) — UTF-16, статически скомпоновано,
BSD-3-Clause. [Исходный код](../MediaInfo/PCRE2/).
[license.txt](../license.txt).
PCRE2 встроена в EXE и не требует отдельной DLL или дополнительной установки.

Выходы:

- Release\MediaInfo.exe
- Debug\MediaInfo.exe

Средство просмотра не связывает среду выполнения C или C++ и не требует распространяемого компонента MSVC.
Выбранный MediaInfo.dll может иметь свои собственные зависимости.

Для сборки требуются Windows PowerShell и .NET Framework. Это только требования к сборке; собственный
исполняемый файл не требует ни PowerShell, ни .NET.

### Дистрибутив

После сборки Release запустите `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\PackageRelease.ps1`
. Сценарий создает `MediaInfo-<version>-win32.zip` в каталоге решения, используя версию исполняемого файла,
состоящую из четырех частей. Архив содержит `MediaInfo.exe` и объединенный `license.txt` непосредственно в его
корне.

## Совместимость

Средство просмотра Win32 предназначено для использования Windows NT 4.0 APIs.

Исполняемый файл включает три библиотеки x86 MediaInfo: 26.10 для текущего Windows, 21.03 из пакета Windows XP
и 0.7.60 из пакета Windows 95–2000. Сама по себе архитектура библиотеки не определяет ее совместимость с
операционной системой. Средство просмотра пробует включенные библиотеки от самых новых до самых старых и
останавливается после первой успешной загрузки и запроса версии.

Windows 95 в настоящее время не поддерживается средой выполнения.

## Использование

- Файл > Открыть (Ctrl+O) открывает диалоговое окно файла Windows с множественным выбором. В версии Windows
  Vista и более поздних версиях операции открытия и сохранения используют современный диалог общих элементов;
  более старые версии Windows используют устаревшие общие диалоги.
- Перетащите один или несколько файлов в окно, на значок EXE или его ярлык либо передайте их пути в командной
  строке. Если несколько экземпляров не разрешены, файлы откроются в уже запущенном окне.
- Каждый отдельный нормализованный полный путь имеет одну вкладку. При повторном открытии уже открытого файла
  выбирается существующая вкладка без перезагрузки или изменения его отчета, выбора или положения прокрутки.
  При сравнении игнорируется регистр букв пути. При открытии нескольких файлов список обрабатывается по
  порядку, и активным остается последний успешно обработанный файл, независимо от того, был ли он открыт
  недавно или уже открыт. При наведении курсора на заголовок вкладки отображается полный путь к файлу во
  встроенной всплывающей подсказке, в том числе в том случае, если отображаемое имя файла сокращено.
- В меню «Файл» перечислены восемь последних загруженных файлов непосредственно над «Выходом» между
  разделителями. Записи показывают только номер и имя файла. При выборе записи открывается сохраненный полный
  путь к ней или выбирается существующая вкладка; успешное повторное открытие перемещает его наверх без
  дубликатов. При выборе недоступного файла возникает вопрос, следует ли удалить запись о последних файлах.
  Используются собственный значок вопроса и кнопки Yes/No. Да — значение по умолчанию, которое удаляет запись
  из меню и реестра; Нет сохраняет это. В приглашении указан полный путь.
- При наведении колеса мыши на переполненные заголовки вкладок полоса заголовков прокручивается на одну
  вкладку для каждого сообщения без изменения выделения или фокуса.
- Ctrl+Tab и Ctrl+Shift+Tab переключают вкладки; Ctrl+W закрывает активную вкладку. Щелчок средней кнопкой
  мыши по заголовку вкладки закрывает эту вкладку, сохраняя при этом любую другую активную вкладку. Команда
  «Файл» > «Закрыть все» закрывает все вкладки, включая отчеты в очереди. Файл > Выход (Alt+F4) закрывает
  приложение.
- Двойной щелчок выделяет слово. Тройной щелчок выбирает логическую линию. Перетаскивание расширяет выделение
  на слова или строки.
- Ctrl+A выбирает отчет; Ctrl+C копирует его.
- Правка > Найти (Ctrl+F) ищет в активной вкладке. F3 повторяет поиск, а Shift+F3 меняет его направление. На
  границе текста поиск продолжается с противоположного конца. Параметры > Перенос по словам действует только в
  активной вкладке; флажок соответствует выбранной вкладке. Окно поиска можно свернуть и изменять его ширину;
  положение и настройка Поверх остальных окон сохраняются. До 30 поисковых текстов с параметрами хранятся
  только до закрытия приложения. Параметры начала и конца относятся к логическим строкам. Регулярные выражения
  используют синтаксис PCRE2. Все команды меню Правка относятся только к активной вкладке. Enter запускает
  поиск, а Shift+Enter меняет выбранное направление на противоположное. «Учитывать регистр» различает
  прописные и строчные буквы; «Искать назад» ищет в сторону начала текста. Выбор записи истории
  восстанавливает все пять параметров поиска, включая состояние режима регулярных выражений; «Поверх остальных
  окон» — независимый параметр. «Регулярное выражение» отключает «Строка начинается с» и «Строка заканчивается
  на». Если включены оба параметра краёв строки, достаточно совпадения на одном краю. «Перенос по словам»
  меняет только отображение.
- Параметры > Настройки (Ctrl+G) открывает единое диалоговое окно настроек для путей MediaInfo и curl, шрифта
  отчета, сглаживания шрифтов, языка интерфейса и языка отчета. Пустой путь DLL включает автоматическое
  обнаружение.
- Кнопка шрифта отображает семейство, размер и стиль и открывает стандартное диалоговое окно шрифта Windows.
  По умолчанию восстанавливается Consolas или Courier New, если Consolas недоступен; кнопка «По умолчанию»
  отключена, пока выбрано значение по умолчанию. Выбранные пользователем шрифты сохраняются без замены кодом
  приложения.
- Варианты сглаживания шрифтов: ClearType, если они поддерживаются, GDI и None. Первоначальный выбор —
  ClearType, если он поддерживается, в противном случае — GDI. Настройки шрифта влияют только на медиа-отчеты
  и экспорт их изображений.
- Справка открывает отдельное немодальное окно с собственной записью на панели задач и кнопкой свертывания. О
  программе — модальный диалог; в заголовке продукта перечислены все три встроенные версии DLL.

Печать… (Ctrl+P) открывает системный диалог выбора принтера и печатает всю активную вкладку без
предварительного просмотра. Используется шрифт отчёта; длинные строки переносятся, а текст разбивается на
страницы. Печать выполняется в фоне.

Открыть папку… открывает файлы непосредственно в выбранной папке, каждый на отдельной вкладке. Вложенные папки
не включаются. Открыть и Открыть папку используют общую последнюю выбранную папку. Экспорт запоминает
отдельную папку, по умолчанию Документы.

Расширенный режим показывает дополнительные поля отчёта.

Полный анализ проверяет весь файл и может занять больше времени. Эти параметры отчета и Уровень трассировки
относятся к каждой вкладке; изменение обновляет только активную вкладку. Последняя выбранная вручную
комбинация сохраняется для новых вкладок и следующего запуска. Соответствующий кэшированный отчет используется
повторно, пока файл остается неизменным.

Известные форматы, Известные кодеки и Известные параметры открываются в собственных вкладках отчёта.

Начальный размер и расположение окна выбираются Windows. Ранее сохраненное расположение окон переопределяет
значения по умолчанию при последующих запусках.

Слева в строке состояния отображаются пути к файлам и ход загрузки, справа — версия загруженной MediaInfo.dll.
Длинные пути сокращаются многоточием с учётом доступного места.

## Создать заголовок

Меню Инструменты — четвёртое в строке меню. Его команда Создать заголовок… открывает один исходный файл
независимо от вкладок отчета и копирует его первые 524288 байт (512 KiB). Более короткий файл копируется
полностью; пустой файл производит пустой вывод. Это обычное чтение двоичного файла без анализа MediaInfo или
требования к MediaInfo.dll. Инструмент оставляет вкладки отчетов и список последних файлов средства просмотра
без изменений.

После прочтения в папке исходного файла открывается диалоговое окно «Сохранить как», в котором предлагается
video.mp4.header для video.mp4: .header добавляется к полному исходному имени. Вы можете изменить как имя, так
и папку назначения. Отмена любого диалога не приводит к выводу данных. Замена существующего пункта назначения
требует подтверждения. Источник остается неизменным; неудачное сохранение сохраняет предыдущий пункт
назначения. Для открытия и сохранения используются самые современные системные диалоговые окна, доступные в
данной версии Windows.

При запуске приложения инструмент берет исходную входную папку из Файл > Открыть. Если ни одна папка не была
сохранена, Windows выбирает исходное местоположение. После выбора входного файла инструмент запоминает
собственную папку только до выхода из приложения, даже если команда «Сохранить как» отменена. Он не изменяет
папки, используемые Открыть и Экспортировать, и не сохраняет свою собственную папку в настройках приложения.
Каждое диалоговое окно «Сохранить как» начинается в папке текущего выбранного входного файла, независимо от
предыдущего места сохранения.

## Поиск библиотек

Сначала проверяется сохраненный вручную путь. Если его невозможно загрузить, автоматическое обнаружение
пытается:

1. MediaInfo.dll рядом с исполняемым файлом, затем в каждом родительском каталоге вплоть до корня диска или
   общего ресурса UNC.
2. ProgramFiles, ProgramFiles(x86) и ProgramW6432.
3. LOCALAPPDATA и APPDATA.

В этих корнях установки обнаружение проверяет MediaInfo, MediaArea\MediaInfo, MediaArea,
MediaArea.net\MediaInfo, Programs\MediaInfo, Programs\MediaArea\MediaInfo. Нечитаемые местоположения и
несовместимые DLLs пропускаются. Он не сканирует диск рекурсивно.

Если совместимый внешний DLL не найден, средство просмотра пробует встроенные версии в следующем порядке:
26.10, 21.03, 0.7.60. Он извлекает и тестирует одну версию за раз. После успешной загрузки версии более старые
версии не извлекаются и не тестируются. Достаточно распространить только MediaInfo.exe; совместимый внешний
DLL всегда имеет приоритет и может обновляться независимо.

Неудачное изменение библиотеки вручную сохраняет уже загруженную библиотеку.

## Экспорт отчета

Форматы «Сохранить как» имеют следующий порядок: TXT, BMP, GIF, JPEG, PNG, TIFF и WebP. Неподдерживаемые
кодировщики исключены как из современных, так и из устаревших диалоговых окон.

TXT предлагает ANSI, UTF-8, UTF-8 с BOM, UTF-16 BE с BOM и UTF-16 LE с BOM. По умолчанию выбран второй
вариант, UTF-8 без BOM. Сохраняются полный текст отчёта и исходные окончания строк.

BMP, PNG и TIFF сохраняют все отображаемые цвета; GIF89a сохраняет точную отображаемую палитру, если
изображение содержит не более 256 цветов. Экспорт всегда записывает выбранный формат или сообщает об ошибке;
он никогда не заменяет другой формат.

## Языки интерфейса и отчетов

Настройки (Параметры > Настройки, Ctrl+G) содержат пути библиотек, шрифт отчёта, сглаживание и языки.
Интерфейс имеет 36 вариантов и изначально следует Windows. Отчёты всегда по умолчанию используют исходный
английский библиотеки, независимо от Windows и интерфейса. Это меняет только ручной выбор: английский, 37
переводов или собственная таблица MediaInfo CSV.

ОК или Применить подтверждает изменения; Отмена отбрасывает неподтверждённые изменения. Настройки задают
ограничение названия вкладки (по умолчанию 80) и очищают список последних файлов. Длинные названия сохраняют
начало, конец и расширение с многоточием посередине.

По умолчанию разрешён только один экземпляр, а последующие запуски передают файлы открытому окну. В настройках
можно разрешить несколько экземпляров. При нескольких окнах только первое окно каждой формы восстанавливает
сохранённое положение; остальные восстанавливают только размер.

Изменение только интерфейса оставляет текст открытых отчетов неизменным. При внесенном вручную изменении языка
отчетов их отчеты перезагружаются, сохраняя порядок табуляции и порядок MRU.

## libcurl

Автоматическое обнаружение curl проверяет выбранные MediaInfo DLL, затем общие executable/ancestor,
программные файлы и места установки пользователя. Если совместимый внешний curl не найден, соответствующая
встроенная текущая версия или XP извлекается в проверенный кэш каждого пользователя. Самый старый MediaInfo
0.7.60 полностью обходит обнаружение, извлечение и загрузку curl. Явно выбранный недействительный curl
отклоняет изменение предпочтения; отсутствие дополнительного автоматического curl не мешает обычным отчетам в
локальном файле.

## Имена файлов и список недавних файлов

Имена файлов MRU сокращаются только в том случае, если их длина превышает 80 UTF-16 кодовых единиц. Среднее
многоточие сохраняет начало, конец имени файла перед его расширением и полное конечное расширение; полные пути
и отчеты остаются неизменными. В заголовках вкладок используется тот же алгоритм с настраиваемым ограничением
по умолчанию 80.

Недавние файлы > Очистить немедленно очищает как активное меню MRU, так и сохраненные пути к нему, оставляя
при этом все открытые вкладки нетронутыми. Он не применяет и не проверяет ожидающие настройки и не включает
функцию «Применить». Отмена или Escape сохраняет очищенную историю, отменяя ожидающие изменения. Очистить
отключается, когда список пуст, и его состояние обновляется, когда список заполняется новыми отчетами. Об
ошибке записи в реестр сообщается немедленно. Применение нового ограничения на имя вкладки обновляет каждую
открытую вкладку без перезагрузки ее медиа-отчета.

### Дополнительные компоненты и системные библиотеки

- Проекты библиотеки Windows позволяют загружать libcurl во время выполнения для MediaInfo, 26.10 и 21.03.
  MediaInfo 0.7.60 был построен с помощью MEDIAINFO_LIBCURL_NO; его двоичный файл также содержит диагностику
  отключенной поддержки. Программа просмотра никогда не обнаруживает, не извлекает и не загружает curl для
  этой встроенной версии.
- libmms отключен во всех трех предоставленных Windows DLLs, что подтверждается их встроенными сообщениями об
  отключении поддержки. Он не перераспределяется.
- Qt и wxWidgets относятся к дополнительным сборкам GUI. Ни один из них не включен ни в эту программу
  просмотра, ни в эти зависимости DLL. Их общие записи были удалены из отображаемой лицензии.
- Graphviz — это необязательный крючок времени выполнения в современном восходящем коде. Никакие Graphviz DLL
  не перераспределяются.
- Плагин FFmpeg не распространяется.
- MediaInfo DLLs напрямую импортирует только KERNEL32.dll. Это не означает, что их статически связанная среда
  выполнения и вспомогательный код отсутствуют.
- Текущий curl напрямую импортирует WS2_32.dll, bcrypt.dll, ADVAPI32.dll, CRYPT32.dll и KERNEL32.dll. XP curl
  напрямую импортирует WS2_32.dll, WLDAP32.dll, ADVAPI32.dll и KERNEL32.dll. Это компоненты Windows. Их
  наличие проверяется загрузчиком Windows.
- Curl сообщает о сборке Windows Schannel/WinSSL, а не о сборке OpenSSL. Сообщаемая дополнительная зависимость
  от сжатия статически включена в zlib. Никакие дополнительные внешние данные, не относящиеся к Windows DLL,
  не отображаются в таблице прямого импорта.
- Сама программа просмотра не имеет зависимости времени выполнения C/C++. Поставляемые сторонние файлы DLLs
  содержат собственные скомпилированные части среды выполнения. В сборках Windows используются инструменты
  Microsoft; нет никаких доказательств, требующих общих инвентарных записей libstdc++ или libc++.
- JPEG использует динамически загружаемую систему GDI+. Упаковщик ресурсов C# и PowerShell являются
  инструментами сборки и не являются зависимостями во время выполнения.

Обычная проверка локальных файлов не требует сервера MediaArea или удаленно загружаемой базы данных формата.
libcurl используется MediaInfo для входов URL и потенциально удаленных ссылок в поддерживаемых форматах
мультимедиа. Его объединение не добавляет в это средство просмотра отдельную команду открытия URL.

### Хранение лицензий и ограничения

Единственное поддерживаемое уведомление о распространении — [license.txt](../license.txt) , закодированное как
UTF-8 с CRLF. Отмеченные пункты о перераспределении BSD, curl, zlib, MIT и Apache не требуют наличия
отдельного файла уведомлений физически рядом с каждым DLL; объединенное уведомление сопровождает их в
исполняемых и распространяемых материалах.

Архивный пакет MediaInfo 0.7.60 использует собственную лицензию для конкретной версии и включает старый текст
GNU Library GPL. Его условия четко отличают немодифицированное двоичное перераспределение от модифицированных
версий; динамическое связывание с помощью этого средства просмотра не изменяет предоставленный DLL. Исходные
условия и сопроводительный текст лицензии сохраняются. Программа просмотра остается с лицензией MIT.

Одна восходящая атрибуция требует квалификации: заголовок Markus Ewald Base64 не имеет явного разрешения или
заявления о лицензии. MediaArea описывает реализацию Bob Withers Base64 как общедоступную в соответствующей
документации MediaConch, но это не устанавливает независимого предоставления лицензии для каждого изменения
Ewald. Для этого заголовка не было изобретено никаких лицензий. Полное подтверждение поставщиком этого
происхождения, точные версии ZenLib и разработка curl commit не были доступны в поставляемых двоичных файлах.
Эти пункты не позволяют рассматривать этот реестр как полный, независимо сертифицированный SBOM.
